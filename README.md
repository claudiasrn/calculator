# Calculator

A fully functional browser-based calculator built with vanilla HTML, CSS, and JavaScript.

## Features

- Addition, subtraction, multiplication, and division
- Decimal support with trailing zero preservation
- Negative number toggle (-/+)
- Chaining operations
- Backspace (DEL) with operator clearing
- Keyboard support
- Divide by zero easter egg 💥

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `0-9` | Digits |
| `+` `-` `*` `/` | Operators |
| `.` or `,` | Decimal point |
| `Enter` or `=` | Equal |
| `Backspace` | Delete |
| `Escape` | Clear |
